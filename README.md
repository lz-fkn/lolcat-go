# lolcat-go
##### ***lazy ass port of busyloop's lolcat to golang***

---

i think it works exactly like [original lolcat](https://github.com/busyloop/lolcat), but now it's more monolithic and easy to port anywhere, where golang works.

---
### compile
make sure you have golang installed, then run those
```
go mod tidy
go build
```

---
### install
either download from releases, or use this
```
go install github.com/lz-fkn/lolcat-go@latest
```
